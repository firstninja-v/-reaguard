# Security

This initial version has not received an independent security audit.

Report suspected vulnerabilities privately to the repository owner. Once available, use GitHub's private vulnerability reporting feature. Do not include secrets or private application code in public issues.

Include the tool version, Node version, operating system, a minimal synthetic reproduction, and the observed impact. Do not treat an easily removable decoy or recoverable minified code as a broken security guarantee: neither is promised to resist a determined analyst.

Never place credentials in client-side code. Hash manifests are unsigned and must be trusted independently.
