# Third-party dependencies

REAguard uses Terser for JavaScript parsing and minification. Exact direct and transitive dependencies are recorded in `package-lock.json`; installing dependencies preserves their package license files in `node_modules`.

When redistributing dependencies or a packaged executable containing them, include their applicable license notices from the installed packages. This document is an inventory pointer, not a replacement for those license texts.

No source code from the reference repository was imported into this implementation. No claim is made that the general concept of release hardening or synthetic decoys is novel.
