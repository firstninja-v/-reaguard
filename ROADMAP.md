# Roadmap

Proposed improvements, not implemented features or delivery promises:

1. Compatibility fixtures from multiple bundlers with original/packaged behavior comparisons.
2. Parse-time, startup-latency, memory and output-size benchmarks across decoy budgets.
3. Repeatable analysis benchmarks comparing minification alone with synthetic data. Publish negative results too.
4. Signed manifests with documented key handling.
5. Bundler integration recipes, followed by adapters where evidence supports them.

Good first contributions: a compatibility fixture, an improved error message with a regression test, or a reproducible performance measurement. Discuss large pipeline changes in an issue first.
